# Auto Gallery

Auto Gallery is a luxury car showroom website designed to showcase premium cars from different brands. The website has a clean, modern layout with a dark theme and gold accents to give it an elegant look.

## Features
- Responsive design for different screen sizes
- Luxury car showcase
- Featured car brands
- Services and about sections
- Testimonials and contact form
- Mobile-friendly navigation

## Built With
- HTML5
- CSS3
- JavaScript

## Getting Started
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

## Note
This project was created as a web design assignment to practice HTML, CSS, Flexbox, Grid, and responsive design.
